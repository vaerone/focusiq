# Focus System

Production-grade focus and accessibility patterns for React.

## Why this exists

Most frontend apps break keyboard navigation and focus management.

This repo shows how to implement:
- Focus lifecycle
- Focus traps
- Roving tabindex
- Real-world debugging patterns

## Patterns included

- Modal (ARIA + focus trap + restore focus)
- Menu (roving tabindex)
- Reusable hooks

## Philosophy

Accessibility is not a checklist.

It is interaction design.
